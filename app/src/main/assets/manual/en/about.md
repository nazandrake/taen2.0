# About

Settings > About names the app and gives its version, its license and a few notes. Taen is a private offline keyboard based on HeliBoard and AOSP. The links on this screen open in your browser; the keyboard itself has no network access.

### {#version}
Shows the version of the app that is installed. Use it when you report a problem or compare with a release.

### {#license}
Taen is open source under the GNU General Public License v3.0. A tap opens the license text of the project in your browser. Code that comes from AOSP is also available under the Apache License 2.0. The file NOTICE in the source lists the other parts and their licenses.

### {#hidden_features}
Opens a short description of things that are easy to miss: long pressing a pinned toolbar key does more (the clipboard key pastes, the move keys move by a word or a page, copy cuts, select word selects all, undo redoes), long pressing a key in the toolbar pins it to the strip, and a long press of the comma key opens the clipboard, emoji, one-handed mode, settings or language switching. See also [Getting started](page:getting-started).

### {#banking_apps}
Some banking apps start only with a system keyboard, because their app shielding allows only the keyboards that came with the phone. Taen cannot change that. Add the **Switch keyboard** tile to Quick Settings and use it to change the keyboard for that app, then change back.

### {#community_links}
Opens links to community pages of the HeliBoard project that Taen is based on: themes, a layout editor and discussions. They open in your browser.

### {#github}
Opens the project page of Taen on GitHub in your browser.
