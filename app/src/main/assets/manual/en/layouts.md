# Secondary layouts

A **layout** is the arrangement of the keys. The main layout (the letters) is chosen for each language under Settings > Languages and layouts ([Languages and layouts](page:languages)). The layouts on this screen are the others: they are shared by all languages. Tap an entry to see the layouts that are available and pick one, or load a layout file of your own. Each entry shows the layout that is in use. The default of each entry is the layout that comes with the app.

### {#layout_SYMBOLS}
The symbols page that opens from the symbols key (the `?123` key). Default: Symbols.

### {#layout_MORE_SYMBOLS}
The second symbols page, reached with the shift key of the symbols page. Default: More symbols.

### {#layout_FUNCTIONAL}
The functional keys: shift, delete, the symbols key, the language key, the emoji key, enter and the keys around the space bar. Default: Functional keys (a tablet version is used on tablets). Change it to move these keys.

### {#layout_NUMBER}
The page for number fields. Default: Numbers.

### {#layout_NUMBER_ROW}
The row of digits above the letters, shown when **Number row** is on ([Preferences](page:preferences)). Default: Number row.

### {#layout_NUMPAD}
The numeric keypad that opens from the numpad toolbar key, from a space bar swipe that you set to toggle the numpad, or from a long press of the symbols key when that is turned on in [Advanced](page:advanced), in portrait. Default: Numpad.

### {#layout_NUMPAD_LANDSCAPE}
The numeric keypad in landscape. Default: Numpad (landscape).

### {#layout_DPAD}
The page of cursor keys that opens from the D-pad key. Default: D-pad.

### {#layout_PHONE}
The page for phone number fields. Default: Phone.

### {#layout_PHONE_SYMBOLS}
The symbols page of phone number fields. Default: Phone symbols.

### {#layout_EMOJI_BOTTOM}
The bottom row of the emoji panel (the key that goes back to the letters and the other keys). Default: Emoji bottom row.

### {#layout_CLIPBOARD_BOTTOM}
The bottom row of the clipboard history. Default: Clipboard bottom row.

### {#layout_VIM_NORMAL}
The keys of Vim Normal mode. Used only when Vim mode is on ([Vim mode](page:vim)). Default: Vim Normal mode. Change it only if you want your own Vim keys.

### {#layout_VIM_VISUAL}
The keys of Vim Visual mode (also used for Visual line and Visual block). Default: Vim Visual mode.
