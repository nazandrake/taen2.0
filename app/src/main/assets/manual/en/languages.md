# Languages and layouts

Settings > Languages and layouts lists every language (and variant) that Taen can type. A switch at the right of each language turns it on or off; tap a language to open its own settings. English (US) and Bulgarian (phonetic) are on after the first start, and dictionaries for English and Bulgarian are part of the app.

## Turn languages on and off

- Use the search at the top to find a language by its name.
- Turn a language on to add it to the language key and the other ways of switching ([Getting started](page:getting-started)). If the language has no dictionary, a dialog says so: you can still type, but there are no suggestions until you add a dictionary ([Dictionaries](page:dictionaries), [Downloads](page:downloads)).
- A language that you added yourself is marked **Custom subtype**, with its extra languages under it.
- With **Remember language per app** in [Preferences](page:preferences), each app keeps its own language.

## The settings of one language

A tap on a language opens a screen for it. It can hold:

- **Multilingual typing**: a second language, so that suggestions come from both. Choose none to type in one language only.
- **Keyboard layout set**: which layout the language uses, for example QWERTY, QWERTZ or AZERTY for Latin languages, or phonetic and BDS for Bulgarian. You can add your own layout from a file and edit or delete it.
- **Popup key order and hints source**, **Show more letters with diacritics in popup** and the **Number row** entries: the same options as in [Preferences](page:preferences) and [Advanced](page:advanced), but only for this language. They start with the global value.
- **Secondary layouts** for this language: the symbols, number and other layouts that this language uses. See [Secondary layouts](page:layouts).
- **Languages with dictionaries**: which dictionaries this language has ([Dictionaries](page:dictionaries)).

The global settings are described on their own pages; this screen only lets you override them for one language. A reset button puts a value back to the global one.

## A word on layouts

A **layout** is the arrangement of the keys. The main layout is chosen per language here. The other layouts (symbols, numbers, phone, emoji row, clipboard row, the Vim layouts) are shared and chosen under Settings > Secondary layouts. Custom layouts are files that you load from your phone. A self-destruct that includes settings removes them.
