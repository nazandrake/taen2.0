# Getting started

Taen is a private keyboard that works without any network access. This page shows how to turn it on, how to switch between keyboards and languages, and what the strip and the toolbar above the keys do. The rest of the manual is under Settings > Help; the index lists every page.

## Turn Taen on

1. Install the app and open it. The welcome screen walks you through the steps.
2. **Enable** Taen in Android's keyboard settings (Languages and input). This allows it to run.
3. **Switch** to Taen: Android shows a keyboard picker where you choose it as the active keyboard.
4. Open any app with a text field. The keyboard shows up. English and Bulgarian are on by default.

The welcome guide shows once. The settings are one tap away from the toolbar: the gear key. After an update, a "What's new" dialog shows once.

## Switch between keyboards

- **Quick Settings tile "Switch keyboard"**: add it from the Quick Settings edit screen. It opens Android's keyboard picker, after the unlock when the phone is locked. It needs no permission and stores nothing.
- **Long press the space bar**: shows the keyboard picker (see **Change input method with space key** in [Advanced](page:advanced)).
- **The language switch key**: the globe key on the bottom row. What it does depends on **Language switch key behavior** in [Preferences](page:preferences): switch language, switch to other keyboards, or both.
- Some banking apps start only with a system keyboard. Taen cannot change that. Use the tile to switch for that app and change back afterwards (see [About](page:about)).

## Switch language

Taen has several ways to change the language. Use the one you like:

- Tap the **language switch key** (the globe).
- **Swipe on the space bar** if you set the swipe to switch language (see **Horizontal spacebar swipe gesture** in [Advanced](page:advanced)).
- **Long press the comma key** and choose Switch language, when the globe key is off.

Add, remove and configure languages under Settings > Languages and layouts ([Languages and layouts](page:languages)). With **Remember language per app** (default on) each app keeps the language you last used in it.

## The suggestion strip and the toolbar

The row above the keys is the strip. In the default mode, **Toolbar keys and suggestions**, it shows:

- the **suggestions** for the word you are typing: tap one to use it.
- at its left, a key that opens the **toolbar**: a row of tools (clipboard, undo and redo, select word, select all, copy, paste, cursor keys and more). Tap the key again to close it. The toolbar **replaces** the strip while it is open.
- the **pinned keys**, always visible beside the suggestions. Voice typing is pinned by default. Long press a toolbar key to pin it.

**Auto hide toolbar** is on by default in this version: when you start typing and suggestions become available, the toolbar closes and the strip comes back. If you want the toolbar to stay, turn that setting off under Settings > Toolbar ([Toolbar](page:toolbar)). If the suggestions seem to have disappeared, see [Troubleshooting](page:troubleshooting).

Long presses on pinned toolbar keys do more: for example, long press the clipboard key to paste, the left or right key to move by a word, the up or down key to move by a page, copy to cut, select word to select all, and undo to redo.

## Type faster

- **Long press** a key for the characters on it (accents, symbols). The hints on the keys show what is there.
- Slide your finger over the letters to type a word by **gesture typing** ([Gesture typing](page:gesture-typing)).
- **Swipe on the space bar** to move the cursor. **Swipe on the delete key** to select and delete more text at once.
- Double tap the space bar to get a full stop and a space (**Double-space period** in [Text correction](page:text-correction)).
- Use **snippets**: short texts that you insert with a tap ([Dictionaries](page:dictionaries)).
- Dictate with the **voice key** ([Voice typing](page:voice)).

## Where to find a setting

Each page of this manual matches a screen of the settings and lists every setting on it, with what it does, its default and when to change it. The pages are in the same order as the settings. The search in the settings finds a setting by its name.

If something does not work as you expect, start with [Troubleshooting](page:troubleshooting).
