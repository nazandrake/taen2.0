# Appearance

Settings > Appearance changes how the keyboard looks: the theme and colors, the size and spacing of the keys, fonts and emoji. Changes apply at once. Entries that appear only when another setting is on say so.

## Theme

### {#theme_style}
The look of the keys: Material, Holo or Rounded. Default: Material. Change it if you prefer the other shapes.

### {#icon_style}
The style of the icons on the keys and the toolbar. By default it follows the theme style. Choose another style if you like those icons better.

### {#accent_shifted_icon}
Draws the shift icon in the accent color when shift is on, so that you see the state at a glance. Default: off.

### {#custom_icon_names}
Lets you pick a different icon for each key of the keyboard and of the toolbar, and reset them all. Use it if an icon is hard to recognize.

### {#theme_key_borders}
Draws a border around each key. Default: off. Turn it on for clearer key edges. It also makes **Key gap scale** appear.

### {#theme_auto_day_night}
Switches between the day and the night colors with Android's dark mode. Default: on. Turn it off to use one set of colors all the time.

### {#theme_colors}
The color theme for the day: a ready-made one (light, dark and others) or your own colors. Opening it lets you edit the color of every part. Default: light.

### {#theme_colors_night}
The color theme for the night. Shown only when the automatic day and night switch is on. Default: dark.

### {#navbar_color}
Colors the Android navigation bar under the keyboard to match it. Default: on.

### {#background_image}
Uses a picture of your own as the keyboard background. The picture is stored encrypted in the app. Pick one that keeps the keys readable.

### {#background_image_landscape}
A background picture for landscape. If it is not set, the portrait picture is used.

## Size and spacing

Each of the next scale entries opens a dialog where you set the value separately for portrait and landscape (and for the split and folded states on phones that fold). Set a value to 100 percent for the plain size.

### {#split_keyboard}
Splits the keyboard in two halves with a gap in the middle, for typing with two thumbs on a large screen. A dialog chooses in which situations it applies: portrait, landscape and, on a foldable phone, folded and folded landscape. Default: off.

### {#split_spacer_scale}
The width of the gap between the halves. Shown only when a split mode is on. Default: 100 percent.

### {#key_gap_scale}
The space between keys. Shown only when key borders are on. Default: 100 percent.

### {#keyboard_height_scale}
The height of the keyboard. Default: 110 percent in portrait, 100 percent in landscape, so that the keys are easier to hit. A height you set yourself is kept. Set 100 percent to go back to the plain size.

### {#bottom_row_scale}
The height of the bottom row (the space bar row) compared to the others. Default: 100 percent.

### {#bottom_padding_scale}
The empty space under the keyboard. Default: 100 percent in portrait, 0 in landscape. Raise it if your thumb hits the system gesture bar.

### {#side_padding_scale}
The empty space at the left and the right of the keyboard. Default: 0. Raise it if the keys at the edge are hard to reach or are covered by the curved edge of the screen.

### {#space_bar_text}
Text that is shown on the space bar. Default: empty. Use it, for example, for the name of the language or a short label.

## Fonts and emoji

### {#custom_font}
Uses a font file from your phone for the keys. Pick a font file; a reset puts the standard font back.

### {#font_scale}
The size of the letters on the keys. Default: 100 percent.

### {#hint_font_scale}
The size of the small hints on the keys. Shown only when key hints are on. Default: 100 percent.

### {#custom_emoji_font}
Uses a font file from your phone for emoji.

### {#emoji_font_scale}
The size of the emoji in the emoji panel. Default: 100 percent.

### {#emoji_key_fit}
Makes the emoji keys grow or shrink together with the emoji. Shown only when the emoji size is not 100 percent. Default: on.

### {#emoji_skin_tone}
The skin tone that emoji with people use by default: neutral or one of the tones. Shown only when the emoji version of the phone supports skin tones. Default: neutral.
